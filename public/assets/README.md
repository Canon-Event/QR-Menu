# FlavorBox Web Asset Pack

This pack converts the approved homepage + pricing mockup into practical web assets.

## Fonts
- Display / headings: **DM Serif Display**
- UI / body: **Manrope**
- Font files are NOT bundled. Use `css/fonts.css` to load them from Google Fonts,
  or self-host licensed files in your own project.

## Core colors
- Forest: `#123A2A`
- Deep Forest: `#0D2B20`
- Orange: `#F15A00`
- Ivory: `#FAF7F1`
- Sage: `#E7EDE5`
- Ink: `#101A15`

## Recommended usage
- Main headings: DM Serif Display, 56–72px desktop
- Section headings: DM Serif Display, 34–48px
- Body: Manrope 16–18px
- Buttons / labels: Manrope 600
- Main CTA: forest background
- Accent words / pricing emphasis: orange
- Large page background: paper / ivory
- Avoid large orange background sections; use orange as a controlled accent.

## Important
The cropped image files are extracted from the concept mockup and are best used as
design references / temporary placeholders. For production, replace the food image
with a properly licensed high-resolution restaurant photo.

The wordmark uses “FlavorBox” because that was the placeholder brand in the mockup.
If your QR menu project's actual name is different, replace the wordmark text while
keeping the QR mark and visual system.
